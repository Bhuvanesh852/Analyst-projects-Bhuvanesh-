# 📊 Financial Analytics Dashboard – Bhuvanesh  (Data Analyst)

A comprehensive **Financial Analytics Dashboard** designed to track, analyze, and visualize **Income vs Expenses** across multiple categories such as Salary, Freelance, Interest, Bonus, Investment, Overtime, Profit, Dividend, Rent, Bills, Dining, Shopping, Transport, Travel, Education, and Healthcare.

## 🚀 Features
- **Income Analysis**: Salary, Freelance, Interest, Bonus, Investment, Overtime, Profit, Dividend  
- **Expense Tracking**: Rent, Bills, Dining, Shopping, Transport, Travel, Education, Healthcare  
- **Pivot Insights**:  
  - Total Income vs Total Expenses  
  - Category-wise breakdown  
  - Monthly trends  
- **KPIs**: Net Savings, Expense Ratio, Category Contribution  
- **Interactive Dashboard**: Filter by month, category, and type  

---
